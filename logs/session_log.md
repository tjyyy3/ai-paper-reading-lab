## 3. 四组答案是怎么生成的（隔离方式）

- 每组一个**独立子会话**，不共享历史。子会话只收到两样东西：该组提示词 + `context/case1_chunk.md` 的全文（内联在消息里，不指向文件）。
- 子会话被明确要求：不读取任何文件、不联网检索、不调用工具、不使用对这篇论文的先验记忆，直接输出答案正文。
- 答案由子会话**自己写入** `outputs/*.md`（用写文件工具原样落盘），我没有改写任何一句。
- 为了降低"模型记得这篇论文"的污染，节选中隐去了题名与作者，只留 arXiv 编号。**这不能消除污染**，见 README 第 9 节局限 2。

## 4. 需要如实说明的三件事

1. **模型身份**：四组答案在 `deepseek-flash` 会话中生成。子会话实际使用的模型标识没有在返回值里暴露，我无法独立核实到具体版本号；温度、top-p 等采样参数不可见。我不编造这些值。
2. **同一会话的措辞漂移**：B 与 C 在"被要求把答案写进文件"时，重述的文本与它前一条消息有轻微措辞差异（内容一致）。仓库里收录的是**写入文件的版本**，并与当时消息中的版本对照过，未发现事实性差异。
3. **第一版锚点定位算法是错的**：第一版用"整句包含"匹配 PDF，20 个锚点只有 6–12 个精确命中（失败源于 PDF 行末断词与跨页段落）。改用"逐词归一 + 5 词词块覆盖率"后为 ok=19 / low=1 / none=0。第一版结果没有保留成文件，教训写在 `docs/method_notes.md`。
