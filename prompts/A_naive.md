# 提示词 A：单遍摘要（naive 基线）

> 对照组 A。这是最常见的用法：把论文片段粘进去，让模型"总结一下主要结论"。
> 除本提示词与 `context/case1_chunk.md` 外，模型不接收任何其他信息。

```text
下面是一篇论文的节选。请用中文帮我总结这篇论文的主要结论，说明它发现了什么、
影响有多大。300 字左右，直接给结论即可。
```

## 为什么这样设计

- 对齐真实场景：研究者读摘要和结果小节时，第一反应就是"帮我总结一下"。
- 不预设输出结构，才能观察模型**自发**会不会带出实验设置、模型清单、反例与不确定性。
- 单轮、无追问、无原文定位要求，是这批模型最常见的默认交互方式。
