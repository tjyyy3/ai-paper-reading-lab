# 让 AI 读论文的结论"能回到原文"：一次可核查的阅读实践

**一句话**：我拿一篇真实论文做了 4 组对照的 AI 阅读实践，结论有点反直觉——**单遍摘要漏掉的不是"结论"，而是"限定条件"；而补上限定条件的瓶颈是"让不让模型展开"，不是"要不要它给证据"。**"结论+锚点+逐字引文"的契约没有提高覆盖面，它买到的是**可核查性**：每条断言都能回到 PDF 的某一页某一段，代价是长度翻倍、以及一个新的失败模式（凑引文）。

- 想看我为什么这么设计：[`docs/method_notes.md`](docs/method_notes.md)

## 1. 我的阅读问题

我在给自己的文献流程选参数时，反复看到一句转述：

> "Lost in the Middle 证明了长上下文模型会忽略中间的信息。"

我想用它来回答一个具体问题：**检索到的文档该按什么顺序塞进 prompt？多检索几篇是不是没用？**

这个转述不足以支撑决策，因为它没告诉我三件事：

1. 忽略到**什么程度**？是掉 2 个点还是掉 20 个点？
2. 在**什么设置**下测的？什么任务、多少文档、哪些模型、什么指标？
3. 有没有**不服从**这个规律的模型或设置？

而这三件事，恰好是"AI 帮我总结一下"最容易漏掉的部分。所以这次实践的目标不是"让 AI 总结这篇论文"，而是：**让 AI 给出的每条结论都带我回到原文，并且用脚本检查它有没有真的回到原文。**

## 2. 材料与案例

| 项目 | 内容 |
| --- | --- |
| 论文 | *Lost in the Middle: How Language Models Use Long Contexts*，Nelson F. Liu 等 7 人 |
| 来源/版本 | arXiv:2307.03172**v3**（2023-11-20），18 页；TACL 2023 接收 |
| 许可 | arXiv.org perpetual non-exclusive license（**非** CC-BY，故本仓库不转载全文） |
| 用到的原文位置 | Abstract、§1、§2.1、§2.2、§2.3（含 Table 1）、§3、§3.2、§4.1、§4.3、§5、§7；PDF p.1–p.11 |
| 输入规模 | 人工摘录 20 个段落/图表，约 1200 词英文原文，标成 20 个锚点 |
| 被测模型 | DeepSeek Harness 会话内的 `deepseek-flash`；**版本号与采样参数不可见，我不编造** |
| 核查工具 | Python 3.12 + pypdf；无 GPU、无向量库、无 RAG 框架 |

摘录的每一段都标了锚点（如 `S23P2` = §2.3 第 2 段），锚点到 PDF 页码的映射由脚本机械生成，见 [`evidence/anchor_pages.md`](evidence/anchor_pages.md)：20 个锚点中 19 个高置信定位，1 个低置信（`S5P2`，覆盖率 0.58，实为跨页段落）。

## 3. 方法：三段式，中间那一段才是关键

```
切分（锚点）  →  提问（输出契约）  →  核查（机械校验 + 人工判定）
```

**切分**：按作者的论证单元（段落）切，而不是按 token 窗口切。因为限定条件往往正好是一段话（§2.1 第 1 段的 "exactly one"），固定窗口会把引文切成两半，校验就无从做起。

**提问**：要求模型输出 `(结论, 锚点, 逐字引文)` 三元组。这是整套方法的核心取舍——只有"逐字"，核查才能降级成一个字符串包含判断；一旦允许改写，"对不对"就变成"意思像不像"，而那正是我们要约束的东西。

**核查**：脚本只做一件事——`canon(引文) ⊂ canon(所引段落)`，其中 `canon` 是"只保留小写字母和数字"的归一键（PDF 会把 `GPT-3.5` 抽成 `GPT-\n3.5`，不归一就对不上）。判定分三类：`ok` / `wrong_anchor`（引文在别的段落里）/ `not_verbatim`（哪儿都没有）。**语义是否支持结论，不由脚本判断**，单独由我人工判定并留档。

为什么不让模型自评：自评会复用它自己的前提。所以核查被拆成"机器管存在性、人管支持性"两层，两层都留原始输出。设计权衡的完整讨论见 [`docs/method_notes.md`](docs/method_notes.md)。

## 4. 实验

四组，**输入完全相同**（同一份 1200 词节选），只改提示词。每组一个独立的会话，会话内被要求不读文件、不联网、不使用先验记忆。

| 组 | 提示词 | 想验证什么 |
| --- | --- | --- |
| **A** | "总结主要结论，300 字左右" | 最常见的默认用法 |
| **A2** | 同 A，但"不限字数，可以写详细" | A 的低覆盖是不是**字数上限**造成的 |
| **B** | 回答三问（结论/设置/限定），每条给锚点+逐字引文 | 证据契约的效果 |
| **C** | 先列"结论成立所需条件"，再核对，再找反例，再分实测/推测 | 条件清单+反例检索的增量 |

A2 是设计实验时才补上的对照组：如果只看 A，我会把"漏掉限定条件"错误归因给"提示词没要求证据"，而真实原因可能是"只要 300 字"。

## 5. 结果

### 5.1 覆盖面：A 只拿到 6/18，A2/B/C 都是 18/18

我把"读者要判断这条结论能不能用"所必需的信息拆成 9 条限定条件（G1–G9），每条附原文引文与页码，见 [`evidence/ground_truth.md`](evidence/ground_truth.md)。逐条判定见 [`verify/coverage_judgement.md`](verify/coverage_judgement.md)。

| 条件 | A | A2 | B | C |
| --- | :-: | :-: | :-: | :-: |
| G1 任务：k 篇里**恰好一篇**含答案 | 0 | 2 | 2 | 2 |
| G2 数据：NQ-Open / 2655 条 / ≤100 token / Contriever | 0 | 2 | 2 | 2 |
| G3 指标：accuracy 判定方式 + greedy 解码 | 1 | 2 | 2 | 2 |
| G4 上下文规模：10/20/30 篇 | 1 | 2 | 2 | 2 |
| G5 模型清单与版本（0613） | 0 | 2 | 2 | 2 |
| G6 量级与基线（>20% / 56.1% / 88.3%） | 2 | 2 | 2 | 2 |
| G7 反例：Claude 近满分 / LongChat 趋势不同 | 0 | 2 | 2 | 2 |
| G8 扩展上下文模型未必更好 | 2 | 2 | 2 | 2 |
| G9 机制是假设 + Flan-UL2 的 2048/1.9% 边界 | 0 | 2 | 2 | 2 |
| **合计** | **6** | **18** | **18** | **18** |

A 的答案本身没有事实错误（我逐句核过），它只是**只写了第 1、6、8 条**。这就是"读起来完整"的危险：一段 343 字的话，语气笃定、数字准确，但读者拿它去决定"要不要调整检索顺序"时，缺的是"这结论只在 10–30 篇文档、6 个模型、字符串命中式打分下测过"和"有模型不服从"。

### 5.2 可核查性：0 → 32/13 条，机械校验 45/45 通过

| 答案 | 证据行 | 通过 | 锚点错配 | 非逐字 | 数字无支撑 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 0 | — | — | — | — |
| A2 | 0 | — | — | — | — |
| B | 32 | 32 | 0 | 0 | 0 |
| C | 13 | 13 | 0 | 0 | 0 |

来源：[`verify/report_all.md`](verify/report_all.md)（脚本输出，未人工修改）。

A/A2 的 0 不是模型的失败——是**契约没要求**：它们给的是自然语言，任何一句都无法定位到原文某一段。B/C 换来的正是这一点：45 条引文全部逐字命中它所声称的段落，且没有一条数字在自己引的段落里找不到。

### 5.3 成本

| 答案 | 长度（字符） | 相对 A 的倍数 |
| --- | ---: | ---: |
| A | 343 | 1.0× |
| A2 | 5 010 | 14.6× |
| B | 11 767 | 34.3× |
| C | 12 816 | 37.4× |

证据契约的成本约为普通详细摘要的 **2.3 倍长度**（B/A2）。这不是免费的：如果每读一篇论文都要付 2.3 倍的输出 token，值不值取决于你要不要复核。

## 6. 我的发现

**F1｜摘要式提问漏的是"限定条件"，不是结论。**
A 把 U 形曲线、20% 降幅、56.1% 闭卷基线、"扩展模型未必更好"都写对了，但 9 条限定里只覆盖 3 条（G3/G4 记 1 分，G6/G8 满分），漏掉的全是"这个结论在什么范围内成立"。证据：A 全文 343 字，见 [`outputs/A_naive.md`](outputs/A_naive.md)；对照 [`evidence/ground_truth.md`](evidence/ground_truth.md)。

**F2｜覆盖面的瓶颈是"让不让展开"，不是"要不要证据"。**
同一句话，只把"300 字左右"改成"不限字数，可以写详细"，覆盖就从 6/18 跳到 18/18，而且没有锚点也能把任务定义、数据、模型清单、反例、假设标注写全。这条直接推翻了我在实验前的假设（原以为必须上证据契约才压得住遗漏）。**实践含义**：与其问"总结一下"，不如问"实验是怎么做的、有哪些例外"；长度限制是覆盖率的一等公民，比提示词风格更重要。

**F3｜证据契约买的是可核查性，不是正确性。**
B/C 的覆盖度与 A2 完全相同（18/18），差别只在"每条结论能不能落到段落"。所以"加了引文要求 = 更准确"是错觉；它换来的是**复核成本下降**（45 条引文全部机械可验，我人工只需判断"是否支持结论"），以及**错误可被发现**。

**F4｜但"引文真实"会被格式逼成"引文凑数"——这是新发现，也是最值得警惕的一点。**
B 有 4 行（表格第 28–31 行）结论是"材料未给出"，却各配了一句**真实但不相关**的引文。例如第 28 行说"query-aware contextualization 的具体设置与结果：材料未给出"，配的引文是 "We empirically study how language models use long input contexts via a series of controlled experiments." —— 这句确实在 §7，校验器判 `ok`，但它完全不支持"材料未给出"。**4/32 ≈ 12.5% 的证据行属于这一类。** 机械校验对它是瞎的，因为问题不在"引文是否存在"，而在"引文是否支持结论"。这说明：**格式化的严谨感会掩盖内容的不严谨**，读者若只看"32/32 通过"会更信任这份答案，反而更危险。

**F5｜C 相对 B 的增量，是"不确定性被显式标注"。**
C 单独列了 5 条反例 + 1 条"'有模型中部优于两端'的反例：材料中未见" + 7 条存疑（含"KV 检索的指标定义材料未给出"）。B 有 hypothesis/实测分区，但没有"材料未给出"清单。对"我要不要相信这条结论"来说，**说清"哪里没有证据"和说清"证据是什么"同样重要**。

**F6｜这套流程自己的错误也要留档，否则它就成了新的"权威"。**
- 我的第一版校验器只认一行里的第一个锚点，把 C 第 12 行（同引 `S21P3`+`S22P1`）误判为"锚点错配"；已改为"任一被引锚点包含即通过"。
- 我的覆盖度扫描器把 A 的"20/30 篇文档"判成"未提及规模"，因为正则写的是 `20 篇`；这是假阴性。
- 两次都是"核查层"自己出错，不是被核查对象出错。所以 `verify/coverage_scan.md` 只作为提示，最终判定是人工的，且判定理由逐条写在 `verify/coverage_judgement.md`。

## 7. 原文 / AI 输出 / 我的判断

这一节把三者分开写，避免读者把模型的话当成论文的话。

| # | 论文原述（位置） | AI 输出 | 我的判断 |
| --- | --- | --- | --- |
| 1 | "performance ... significantly degrades when models must access relevant information in the middle of long contexts, **even for explicitly long-context models**."（Abstract，p.1） | A："即使专门的扩展上下文模型也如此。"（`outputs/A_naive.md`） | 措辞与原文一致，但这句话常被读成"所有长上下文模型都差"。原文的实际支撑范围是 6 个模型、10–30 篇文档、字符串命中式打分；§2.3 同时说扩展版与非扩展版"nearly identical"——它反驳的是"窗口更大就更会用"，不是"所有长上下文模型都无效"。**这是本案例里最容易被误用的一句。** |
| 2 | 原文只有 "we **qualitatively observe** that ... LongChat-13B (16K) tends to generate code to retrieve the key"（§3.2，p.6） | A2 第 43 行："这更像格式遵循/指令跟随层面的失败，而非单纯检索失败。" | 这是 A2 自己的解释，原文没有给原因。A2 用"更像"做了不确定性标记，但严格说这属于**超出节选证据的推断**，不应写进读者笔记的"原文结论"栏。 |
| 3 | §7 原文："We empirically study how language models use long input contexts..."（p.11） | B 表格第 28 行把它当作"query-aware contextualization 材料未给出"的引文 | 引文逐字为真、锚点正确，但**不支持该结论**。这类"真实错配"是机械校验的盲区，也是我建议所有"AI 读论文"流程都要人工抽查的原因。 |

## 8. 复现步骤

### 8.1 环境

```bash
python -m pip install pypdf          # 唯一依赖；Python 3.10+ 均可
```

论文本体请自行下载（本仓库不分发全文）：

```bash
# 浏览器打开 https://arxiv.org/abs/2307.03172v3 ，下载 PDF，存为任意路径
```

### 8.2 跑通三个脚本（约 10 秒）

```bash
# 1) 锚点 → 页码：验证节选没有被我改写
python tools/locate_anchors.py --pdf /path/to/paper.pdf \
    --chunk context/case1_chunk.md --out evidence/anchor_pages.md
# 期望：20 个锚点，ok=19 low=1 none=0

# 2) 引文机械校验
python verify/check_answers.py --chunk context/case1_chunk.md \
    --answers outputs/A_naive.md outputs/A2_naive_nolimit.md \
              outputs/B_evidence.md outputs/C_conditions.md --outdir verify
# 期望：B 32 行全 ok；C 13 行全 ok；A/A2 0 行（因为没有表格）

# 3) 覆盖度扫描（机械提示，非结论）
python tools/coverage_scan.py --answers outputs/A_naive.md \
    outputs/A2_naive_nolimit.md outputs/B_evidence.md \
    outputs/C_conditions.md --out verify/coverage_scan.md
```

### 8.3 重做 AI 阅读（用你自己的模型）

1. 打开 `context/case1_chunk.md`，把里面 20 个锚点段落（从 `<<ABS>>` 到最后一个 `<<END>>`）整段复制；
2. 新开一个**干净的会话**（不要带任何历史对话），粘贴 `prompts/A_naive.md` / `B_evidence.md` / `C_conditions.md` 里的提示词，再把节选贴在后面；
3. 把回答原样存成 `outputs/你的文件名.md`（不要编辑措辞，否则校验失去意义）；
4. 重跑 8.2 的第 2、3 步。

**怎么判断结果符合预期**：B/C 的答案里，每条结论都应该有锚点和引文；脚本应当给出高通过率。如果出现大量 `wrong_anchor` / `not_verbatim`，说明你的模型在"背原文"而不是"抄原文"——这正是校验器存在的意义，此时应要求它重新从段落里复制。

### 8.4 检查一张表就够了

对照 `evidence/ground_truth.md` 的 G1–G9，逐条在答案里找"有没有写、写得对不对"。这就是我做人工判定时用的方法，`verify/coverage_judgement.md` 是它的完整留档。

## 9. 局限（诚实清单）

1. **样本极小**：1 篇论文、1 份节选、1 个模型、每组 1 次。不能当作"提示词效应"的一般结论，只能说"在这个案例里观察到"。
2. **未严格盲测**：我只隐去了题名与作者，并要求禁网。这篇论文很知名，模型可能"记得"它——记忆泄漏会**抬高** A2/B/C 的覆盖度，因此不能用它解释 A 的低分；但反过来，A2/B/C 的 18/18 可能部分来自记忆，而非对节选的阅读。
3. **A 与 A2 的差异可能混入其他因素**：字数放宽的同时，提示词也多了"实验是怎么做的"这半句。严格说这是两个变量，不是纯字数对照。我没有再补一组"只放宽字数、不加问法"来分离它们，这是本实践未完成的验证。
4. **节选有删节**：为控制篇幅，我删掉了引用括号并标 `[...]`，因此锚点与 PDF 的机械匹配覆盖率在 0.58–1.00 之间（`S5P2` 低于阈值）。
5. **覆盖度评分是单人判断**：标准固定在 `ground_truth.md`，但 1/2 分的边界仍有主观空间；我没有做双人标注与一致性检验。
6. **未测其他模型与多次采样**：不同模型、不同温度、重复 5 次，结果都可能变化。不做这些，就不能声称"稳定"。
7. **没有平台特定结论**：本实践在通用 LLM 会话中完成，未在任何特定科研平台上验证，因此不声称任何平台特有的效果。
